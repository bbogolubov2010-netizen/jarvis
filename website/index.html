Features

Why JARVIS?

JARVIS keeps AI inference on your machine, asks before risky actions, and states its network boundaries plainly.

Local AI Inference

Powered by Ollama. Model inference runs on your hardware — no cloud AI service, no subscription, no API key.

Vision & Screen Analysis

Capture your screen and ask a question about it. Requires a vision-capable model such as llava; the screenshot stays on your machine.

Smart Web Search

Ask JARVIS to research something. It sends the query to DuckDuckGo, reads the first result, and summarizes it. Available only when web search is enabled.

System Automation

Open detected apps, control volume, take screenshots, shut down, or restart. Screenshots, /open commands, shutdown, and restart require confirmation.

AI Image Generation

Generate images from text descriptions through Pollinations.ai. This is an online service: your prompt leaves the machine.

Global Hotkey

Press Ctrl+Shift+J from anywhere to show or hide JARVIS without leaving the current app.

File Management

Create, read, write files and folders. JARVIS can organize your Desktop and Documents.

In-Session and Saved Notes

Save notes with /note and list them with /notes. Notes are stored as JSON in your JARVIS config folder.

System Tray Integration

JARVIS lives in your system tray. Left-click toggles the window; right-click opens a menu with Show / Hide and Quit.

Security First

Local by Design

Practical safeguards, with the network boundaries stated plainly.

DPAPI Encryption

Settings are encrypted with Windows DPAPI for your user account.

Confirmation for Actions

Screenshots, web search, shutdown, restart, and /open require an explicit YES. Clicking an app in the sidebar launches it directly. Web search and image generation use third-party services.

Prompt Injection Shield

Web content is sanitized before it reaches the model and is treated as untrusted data. This reduces risk; it is not a guarantee.

Local Audit Log

Commands, searches, and confirmations are logged locally. Type /audit to see recent entries.

How It Works

From Source to Commander

JARVIS is not yet distributed as a signed installer. Build it from source in a few steps.

1. Install Ollama

Download Ollama from ollama.com and install it. The free, open-source model runner is the only heavy dependency.

2. Pull a Model

JARVIS will detect your RAM and recommend the best model. One command installs it.

3. Build and Launch JARVIS

Install Go, Node.js, and the Wails CLI, then follow the README. The app appears in your system tray; press Ctrl+Shift+J to toggle it.

4. Start Commanding

Type anything. "/smart quantum computing", "/screen", "/volume 40", "/open Spotify" — JARVIS responds.

FAQ

Frequently Asked

Is JARVIS really free?
Yes. JARVIS is 100% free and open source. No subscriptions, no paid tiers, no hidden costs. You only need to run Ollama, which is also free.
Does JARVIS send my data anywhere?
Model inference stays on your machine. Two optional features use the internet: web search sends your query to DuckDuckGo, and image generation sends your prompt to Pollinations.ai. JARVIS has no telemetry or analytics.
What hardware do I need?
Any Windows 10/11 PC with 8 GB RAM for small models; 16 GB or more is recommended. A GPU is optional but accelerates responses. JARVIS reads your RAM and recommends a model during setup.
Can I use my own AI model?
Absolutely. JARVIS works with any model available in Ollama. Switch models from the Settings panel anytime — from tiny 1B models to massive 70B models.
How is JARVIS different from ChatGPT?
ChatGPT is a hosted service. JARVIS is a desktop application with OS integration: it can read your screen, open programs, control volume, and manage files. Model inference is local; web search and image generation are optional online extras.
Is JARVIS safe to use?
JARVIS uses several safeguards: DPAPI encryption for settings, a path allowlist for file operations, prompt-injection sanitization, explicit confirmation for risky system and network actions, and a local audit log. No desktop assistant is risk-free, so review what you ask it to do.
